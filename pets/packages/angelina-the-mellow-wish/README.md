# Angelina the Mellow Wish

双击 `Angelina the Mellow Wish.exe` 启动桌宠，无需安装。

## 操作方式

- 初始姿态：`relax`
- 左键：播放 `interact`，结束后固定回到 `relax`
- 右键：选择 `relax`、`sit`、`sleep` 或 `move`
- `move` 模式：自动跟随鼠标
- `move` 模式按住 WASD：键盘控制移动
- 同时按住 Shift：2 倍移动速度
- 右键菜单也可退出
- `Alt+F4`：退出
